СЕТЬ И ИНТЕГРАЦИИ

Подключение

Для изменения настроек войдите с паролем устройства.

Сеть Wi-Fi

Подключите датчик к сети 2,4 ГГц.

После смены сети адрес устройства может измениться. Резервная точка доступа позволяет продолжить настройку.

MQTT и Home Assistant

Оставьте адрес брокера пустым для автономной работы.

CA-сертификат

Состояние пока неизвестно

До 4 КБ. Новый сертификат заменит предыдущий только после успешной проверки.

Всегда рядом

Этот интерфейс работает прямо на датчике. Для просмотра давления интернет не нужен.

Если домашняя сеть недоступна, подключитесь к резервной сети WaterSensor-… и откройте 192.168.4.1.

Пароль интерфейса и резервной сети выводится в USB Serial при запуске, а при настройке — на OLED.

РАСЧЁТ ПО ВВЕДЁННЫМ ПАРАМЕТРАМ

Измеримый диапазон

—

бар

Сверьте показания с контрольным манометром в нескольких точках диапазона. Сохранение параметров перезапускает фильтр измерений.

Настройка шкалы не защищает вход A0 от перенапряжения. Датчику 0,5–4,5 В нужен согласующий делитель. Схема и расчёт приведены в README.

Обновление прошивки

Загрузите firmware.bin, собранный для D1 mini.

Настройки и CA-сертификат сохраняются. Во время записи не отключайте питание.

Пароль интерфейса

Он также используется для резервной сети Wi-Fi.

8–63 печатных символа ASCII без пробелов. Для резервной сети пароль обновится после перезагрузки.

Перезагрузка

Измерения и соединение прервутся на время запуска.

Доступ к настройкам защищён паролем. Сам веб-интерфейс использует HTTP; подключайтесь к устройству в доверенной локальной сети.
