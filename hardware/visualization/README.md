# Визуализация сборки A3

Плата-носитель 36 × 60 мм взята из сохранённого `hardware/WaterPressureSensor.kicad_pcb`.
Положение, ориентация, отверстия и дорожки — из реального файла платы.
Исходный PCB не изменяется. Для визуализации добавлены три локальные модели VRML:
WeMos D1 Mini с USB-C и двумя гнёздами 1×8, OLED SSD1306 с высоким разъёмом 1×4,
гнездо RJ-10 4P4C.

## Просмотр

- `assembly-isometric.png` — общий вид сборки.
- `assembly-side.png` — вид со стороны USB: виден второй ярус и высокий разъём OLED.
- `assembly-top.png` — вид сверху.
- `WaterPressureSensor-assembled.kicad_pcb` — открыть в редакторе платы KiCad,
  затем **Alt+3** для 3D-просмотра. Папка `models` должна оставаться рядом с PCB.

## Допущения моделей

Это габаритная визуализация, а не сборка из точных моделей производителя.
Форма USB-C/RJ-10, корпус экрана, размещение микросхем, деталей и антенны на
WeMos показаны приближённо. Модели не подтверждают посадку, зазоры, доступ
кабелей или совпадение с конкретной ревизией модулей.

Приняты высоты относительно верхней поверхности носителя:

| Элемент | Высота, мм |
|---|---:|
| Гнёзда WeMos, верх корпуса | 8,5 |
| Плата WeMos, низ / верх | 11,0 / 12,0 |
| USB-C, верх | 15,25 |
| Высокий разъём OLED, верх корпуса | 18,67 |
| Плата OLED, низ / верх | 21,17 / 22,37 |
| Экран OLED, верх | около 23,75 |
| RJ-10, верх | 11,4 |

Высота корпуса разъёма OLED 18,67 мм взята из ранее выбранного ESW-104-44-G-S.
Остальные высоты и сочленение гребёнок приняты для визуализации; требуется
сверка с реальными деталями. Отдельная опора свободного края OLED, винты,
корпус устройства и подключённые кабели не моделировались.

Экран показывает **2.50 BAR / DEMO** — это иллюстрация, не показание датчика.
Файл `assembly-assumptions.json` содержит допущения и SHA-256 исходного PCB.
Генератор моделей: `../tools/build_assembly_visual.py`, запускать Python из KiCad.
Эта копия PCB предназначена для просмотра; рабочий источник остаётся в папке `hardware`.
