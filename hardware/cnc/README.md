# CNC 3018 / GRBL 1.1 — WaterPressureSensor A3

Подготовлено 18.10.2026 по текущей плате 36 × 60 мм, только B.Cu.
Подтверждено пользователем: текстолит 2 мм, медь 70 мкм; сухой УФ-фоторезист,
FeCl3, приклейка к жертвенному столу, Z-probe; свёрла 1 / 1,5 / 2 мм,
V-гравер 30° с кончиком 0,2 мм. Рекомендованный отправитель — bCNC.

Для запуска установленного bCNC на Windows использовать `Start-bCNC.cmd`:
он выбирает отдельный Python 3.11 / NumPy 1.26 / Tk 8.6. Порядок установки и
результат проверки — [BCNC-Windows.md](BCNC-Windows.md). Обычная команда
`python -m bCNC` может выбирать несовместимый системный Python 3.15 / Tk 9.

**Все режущие УП требуют проверки настройки и пробы на обрезке.** Ни один файл
не запускался на станке. S10000, подачи, глубины и безопасный Z — пробные значения.
Значения $30/$31/$32, геометрия сверла, реальная толщина/коробление, биение и
пределы станка неизвестны. Подробный материал/статус — `manifest.json`.
Основной файл PCB сохранён без изменений; материал в старой документации A3
1,6 мм / 35 мкм не использовать для этих УП. Для CAM приняты новые данные 2 мм / 70 мкм.

| Файл в jobs | Назначение и ограничение |
|---|---|
| 01_contacts_D1mm_SETUP_REQUIRED.ngc | 24 контактных отверстия, фактически Ø1 мм. Четыре номинальных Ø0,9 мм расширяются до Ø1 мм только в CAM; проверьте фиксацию RJ-10. |
| 02_PILOTS_ONLY_D2mm_SETUP_REQUIRED.ngc | 6 пилотных Ø2 мм. Это НЕ готовые 5×Ø3,2 + 1×Ø3,25 мм. |
| 03_EXPERIMENT_resist_clear_UNLEVELLED.ngc | Только эксперимент с полностью отверждённым резистом: снимает резист вне меди; Z0 по голой меди, Zwork −0,005 мм. Требует проверки плёнки, биения и карты высот. Не обычная засветка/проявление, не обработка меди 70 мкм. |
| 04_outline_REQUIRES_ENDMILL_1mm.ngc | Контур с четырьмя перемычками; требуется концевая фреза Ø1 мм, которой нет в указанном наборе. |
| 05_largeholes_REQUIRES_ENDMILL_1mm.ngc | Окончательные Ø3,2/3,25 мм концевой фрезой Ø1 мм после пилотных Ø2 мм. Также требует отсутствующий инструмент. |

В `dryrun/` — соответствующие отдельные программы **M5, весь Z=+5 мм**;
M3 удалён, M30 сохранён. Перед сухим прогоном отключить height map и проверить
реальную высоту +5 мм, прижимы и G54. Программа не меняет рабочий ноль.

В `phototools/` — PDF A4 и SVG с векторным рисунком 1:1:

- `negative_PRINT_INK_DOWN`: для НЕГАТИВНОГО резиста, прозрачные дорожки/площадки,
  чёрные пробелы. Печатать 100%, без Fit; печатная сторона должна касаться резиста.
- `positive_PRINT_INK_DOWN`: противоположная полярность для ПОЗИТИВНОГО резиста.
- `negative_BOTTOM_VIEW_CONTROL`: контрольный вид со стороны меди; не использовать
  вместо мастер-шаблона при развороте печатной стороной вниз.

Тип резиста не определён по названию «сухой УФ»: сверьте инструкцию плёнки.
Разворот печатной стороной к резисту сам зеркалирует изображение; поэтому
мастер INK_DOWN намеренно отличается от контрольного вида BOTTOM_VIEW.
Проверяйте асимметричный RJ-10 и контакт 1. Чёрная печать должна перекрывать УФ,
а не только выглядеть чёрной при комнатном освещении. Контрольные риски — 10 мм.

## Координаты и экспорт KiCad

`inputs/WaterPressureSensor-CAM.kicad_pcb` — отдельная CAM-копия: Drill/Place Origin
поставлен в (0,60) исходной платы, т.е. в нижний левый угол при виде сверху.
Grid Origin и Drill/Place Origin в KiCad — разные настройки. Для Gerber и Excellon
используется один Drill/Place Origin, без исходного зеркалирования.

Экспорт: Gerber RS-274X, мм, 4.6; B.Cu и Edge.Cuts отдельными файлами,
без сверлильных меток и рамки листа. Excellon — мм, абсолютные десятичные координаты,
полный заголовок, Minimal header выключен, Mirror Y выключен. 4.6 относится
к Gerber; десятичный Excellon не требует угадывания разрядности/подавления нулей.
Сверловка PTH/NPTH для домашнего изготовления сведена вместе; металлизация не создаётся.
`contacts_D1mm.drl` и `pilots_D2mm.drl` — отдельные CAM-подстановки под имеющиеся свёрла.

Команда воспроизведения (из корня проекта, требует установленный KiCad):

```powershell
& .\hardware\cnc\export_inputs.ps1
```

Выполненные этим скриптом команды:

```powershell
kicad-cli pcb export gerbers --layers 'B.Cu,Edge.Cuts' --precision 6 --use-drill-file-origin --no-x2 --output inputs/ inputs/WaterPressureSensor-CAM.kicad_pcb
kicad-cli pcb export drill --format excellon --drill-origin plot --excellon-units mm --excellon-zeros-format decimal --generate-map --map-format pdf --output inputs/ inputs/WaterPressureSensor-CAM.kicad_pcb
```

Для имеющейся платы работаем медью вверх, G54 XY в нижнем левом углу контрольного
вида BOTTOM_VIEW, Z0 по голой меди. Преобразование из исходного PCB с Y вниз:
**Xcnc=36−Xpcb, Ycnc=60−Ypcb.** Готовые jobs/dryrun уже преобразованы;
их НЕЛЬЗЯ зеркалировать ещё раз. Сырьё `inputs/*.gbl/*.drl` НЕ зеркалировано;
при новом CAM оно преобразуется ровно один раз с той же базой.

Оставить 5–10 мм запаса заготовки под крепление/базирование. Контурный инструмент
Ø1 мм имеет осевую траекторию X=−0,5…36,5 / Y=−0,5…60,5; с радиусом инструмента
обработка достигает X=−1…37 / Y=−1…61 мм. Согласовать это с реальной заготовкой.
Отрицательные рабочие координаты допустимы, если фактическое машинное положение
и жертвенный стол дают нужный запас. Рабочий G54 не равен машинному нулю.

Для будущей двусторонней платы или повторной установки после травления:
просверлить два базовых отверстия Ø2 мм в технологических полях и жертвенном столе,
применять штифты и отдельное крепление. База должна оставаться на панели до конца.
Пример оси отражения X=18 и штифтов (18,−5), (18,65) применим ТОЛЬКО если хватает
поля заготовки и ходов; эти дополнительные отверстия в готовых УП не добавлены.
При перевороте вокруг линии, параллельной Y, меняется координата X: X'=36−X.
В FlatCAM это Mirror Axis=Y, Point=(18,30); название «зеркало по X» неоднозначно.
Если физически переворачивать вокруг X, отражать надо Y. После переворота — новая
карта высот и Z0. Для текущей односторонней платы переворот между сверлением
и обработкой рисунка не нужен. Повторная посадка после ламинирования/травления нужна.

## Пробные режимы

Все подачи мм/мин, глубины относительно указанного Z0. Это не паспортные режимы станка.

| Операция | Инструмент | S / ориентир об/мин | XY | Z | Глубина |
|---|---|---:|---:|---:|---|
| 24 контакта | Сверло Ø1 мм | 10000*, ориентир 8000–10000 | G0 на безопасном Z | 60 | −2,50; peck 0,35 |
| 6 пилотных | Сверло Ø2 мм | 10000*, ориентир 8000–10000 | G0 на безопасном Z | 40 | −2,85; peck 0,30 |
| Эксперимент с резистом | V30°, кончик 0,2 | 10000*, проверить чистоту реза | 150 | 30 | −0,005 от ГОЛОЙ меди, не от верха плёнки |
| Большие отверстия | Концевая Ø1 мм, отсутствует | 10000* | 100 | 40 | −2,20; шаг 0,20 |
| Контур | Концевая Ø1 мм, отсутствует | 10000* | 120 | 40 | −2,20; шаг 0,20 |

*S10000 означает 10000 об/мин только при согласованном $30 и драйвере шпинделя.
Сначала сохранить вывод `$$`, `$G`, `$#`, `$I`; для фрезеровки проверить $32=0.
Если $30=1000, S10000 обычно насыщает PWM, а не делает двигатель в 10 раз быстрее.
$30 не измеряет реальные обороты. Не менять настройки вслепую; проверить тахометром
или известной калибровкой драйвера. Пробная пауза раскрутки G4 P2 — 2 секунды.

Глубина сверления зависит от полной толщины (измерить, включая медь) и острия:
**Zfinish = −(t + D/[2·tan(угол_острия/2)] + запас)**. Для условных t≤2,1 мм,
острия 118° и запаса 0,1 мм получаются около −2,5 мм (D1) и −2,8 мм (D2).
Именно это заложено; другие свёрла/реальная толщина требуют пересчёта.
В каждом peck инструмент возвращается к Z=+0,5; перед сменой XY — к +5.
До алюминиевого стола нужен запас не менее 1 мм в жертвенном слое под платой:
пилотное сверло опускается примерно на 0,8 мм ниже оборотной поверхности.
Проверить, что +5 выше крепежа и Z=+8 для смены инструмента помещается в реальный ход.
Порядок: контакты Ø1, пилоты Ø2, окончательные большие отверстия, контур последним.
Ø1,5 не нужен для контактов. Не делать отверстия 3,2/3,25 боковым раскачиванием сверла.

GRBL 1.1 не исполняет G81/G83, M6, G41/G42, макросы O/#/циклы LinuxCNC.
Поддерживает G0/G1, G2/G3, G38.2, M0, M3/M5, M2/M30. Перед сменой инструмента:
вывести Z, M5, дождаться остановки, M0 / конец отдельной УП, сменить инструмент,
заново определить Z0 по меди; XY и установку заготовки сохранять. M0 сам не равен M5.
Не полагаться на незаданные G28/G30. Не обнулять XYZ внутри рабочего файла.

## Сухой УФ-фоторезист и травление

Рекомендуемый процесс:

1. При необходимости сделать базовые отверстия в полях панели, зачистить заусенцы.
2. Подготовить ровную медь, обезжирить и высушить; ламинировать по инструкции
   плёнки, сняв её нижнюю защитную плёнку. Температура/скорость не назначаются без марки.
3. Проверить негативный/позитивный тип на тестовом фрагменте. Для негативного
   резиста свет должен пройти в дорожки/площадки; засвеченный полимер остаётся.
   Для позитивного резиста чёрными закрывают сохраняемые дорожки.
4. Положить мастер-шаблон печатной стороной к резисту, обеспечить плотный контакт.
   Верхний PET у типового сухого резиста обычно сохраняют при засветке, снимают
   перед проявлением; точная последовательность — по инструкции конкретной плёнки.
5. Подобрать экспозицию тестовой лестницей, проявить штатным проявителем,
   промыть по инструкции. В пробелах должна быть чистая медь, без остаточной вуали.
6. Протравить FeCl3 в совместимой пластиковой ёмкости, отдельно от ЧПУ.
   Использовать концентрацию/температуру поставщика. Например, готовые составы
   могут применяться без разбавления; универсального рецепта нет. При 70 мкм
   процесс дольше и подтравливание сильнее, чем при 35 мкм: следить за окончанием
   удаления меди, не передерживать. Не удваивать время механически.
7. Промыть, снять резист штатным средством, высушить; сверлить после травления.
   При повторной установке использовать штифты/базу, проверить совпадение нескольких
   площадок, затем выполнить контактные/пилотные отверстия, большие отверстия, контур.
8. Осмотреть зазоры, прозвонить все сети и замыкания, удалить заусенцы, залудить по необходимости.

Резист защищает медь под ним; фрезой при обычной УФ-технологии рисунок не делают.
Здесь CNC делает отверстия и контур, рисунок задаёт фотошаблон.

Если обязательно нужен рисунок станком, экспериментальная УП 03 работает иначе:
равномерно отвердить негативную плёнку на тестовом купоне, удалить защитный PET,
механически вскрыть до меди ВСЕ пробелы и затем травить. Это нестандартный процесс:
устойчивость к FeCl3, адгезия, сколы и глубина проверяются на купоне. После полной
засветки обычный проявитель уже не создаст рисунок из нетронутой плёнки.
Не гравировать необработанный резист и затем ждать рисунка от проявления без
нужной экспозиции. Кончик сквозь резист при электрическом probing его повреждает.

УП 03 строит полный растровый NCC по полигонам KiCad, оставляя резист на площадках
и дорожках. Шаг 0,1 мм, номинальная ширина инструмента 0,20268 мм, дополнительный
защитный отступ 0,01 мм. Это даёт небольшое увеличение защищаемой меди и гребешки
на краях; не точная оптическая реплика. Режим требует измерения ширины реза.
Около 19,9 м резания, 133 мин без учёта 2227 подъёмов/погружений и холостого хода.
Обычная Isolation Routing вокруг дорожек оставит покрытые резистом медные острова.
Полное снятие пробелов особенно важно под антенной WeMos.

30° принят полным углом V-гравера. **dэфф = dкончика + 2·h·tan(30°/2)**. При фрезеровании меди 70 мкм
нужен h хотя бы 0,07 мм, обычно больше на реальную неровность/запас; при h=0,10
dэфф≈0,254 мм — уже больше зазора 0,25, до добавления биения. Поэтому этот гравер
не выбран для прямого прорезания меди данной платы. При снятии резиста −0,005
от голой меди dэфф≈0,203 мм; от верха плёнки глубина составит её толщину +0,005.
Это геометрическая оценка, не гарантия для шпинделя 775.

Альтернативы: самоклеящаяся травильная маска — прорезать границы и выбрать плёнку
из пробелов, предварительно проверить клей/плёнку в FeCl3; жидкий etch-resist —
нанести отдельно кистью/валиком/распылением, затем вскрывать пробелы; непрозрачный
слой на прозрачном фотошаблоне — станок снимает его в зонах, где должен пройти УФ,
а сам резист на меди остаётся целым. Эти материалы не взаимозаменяемы с сухой
УФ-плёнкой; размер кончика, глубину и схему инверсии нужно пересчитать под метод.

## Автоуровень bCNC

1. На закреплённой голой меди проверить цепь щупа при выключенном шпинделе,
   состояние Pn:P, режим $6 и отсутствие проводов в зоне вращения.
2. Выполнить homing, если он установлен/настроен. Зафиксировать G54, очистить
   старую карту. При отсутствии homing не считать soft limits надёжной защитой.
3. Для поля 36×60 начальная сетка 5×5 мм: X=0…36 (9 узлов, фактический шаг 4,5),
   Y=0…60 (13 узлов, шаг 5), всего 117 точек. При локальной деформации шаг 2–3 мм.
   Эти координаты сканируют только медь в пределах платы. Если обработка/растры
   выходят за край, включить соответствующее поле ЗАГОТОВКИ в карту и согласовать
   шаг/число точек. Не пробовать за границей меди и не экстраполировать карту.
4. Начальные пробные настройки: Zmax=+2 мм, Zmin=−0,3 мм от предварительно
   установленного нуля, Fprobe=20–30 мм/мин. Не брать большой ход вниз «на всякий случай».
   Повторяемость по одной точке желательно ≤0,01 мм, остаточная ошибка 0,01–0,02 мм;
   при перепаде порядка 0,2 мм сначала исправить крепление/стол. Это рабочие цели,
   не гарантированные характеристики 3018.
5. Пример одиночного теста из известного безопасного положения возле поверхности:

```gcode
G21 G90 G94
M5
G91
G38.2 Z-0.5 F20
G90
```

   Щуп должен сработать раньше 0,5 мм; эта команда не обнуляет Z сама.
   Положение, толщину контактной пластины и ноль назначать средствами bCNC отдельно.
6. Привязать карту кнопкой Zero к выбранной физической опорной точке и согласовать
   Z0. Сохранить `.probe`. Карта зависит от стороны, установки и G54.
7. Применять компенсацию один раз: карта активна при передаче ИЛИ сохранён уже
   компенсированный G-code. Не делать оба действия. Проверить, не подгрузился
   старый `.probe` автоматически по имени файла.
8. Проверять и исходную, и фактически компенсированную УП. Бюджет Z учитывать
   по минимуму/максимуму карты; номинальные −0,005 не означают такой же минимум
   в глобальном G54. Для сверления/контура перепад поверхности влияет на выход/остаток tabs.

Резист не проводит ток. Обычный электрический щуп не измеряет его верхнюю поверхность.
Карта до ламинирования допустима только при доказанной повторяемости после нагрева/
повторной посадки и с правильной привязкой к голой меди. Если форма изменилась,
карта недействительна. Для надёжной механической обработки покрытой плёнки нужен
механический/силовой щуп, контролируемый плавающий инструмент или иной способ
измерения её поверхности.

**После травления регулярная электрическая сетка тоже не работает:** в пробелах
уже FR-4, а оставшиеся площадки и цепи электрически разобщены. Для маршрута
УФ → травление → сверловка задавайте Z0 по подключённой площадке или отдельной
контактной пластине с учётом её толщины и опорной поверхности. При ровной приклейке
для сверления/контура допустим контроль плоскости и запас глубины вместо полной
карты. Если полная карта нужна на вытравленной плате, необходим механический щуп
или отдельная проверенная методика; не запускайте G38.2 вслепую в пробелах.

## Контур и большие отверстия

Не использовать V-фрезу или сверло как концевую фрезу. Для предложенных УП 04/05
нужна центрорежущая твердосплавная концевая фреза Ø1 мм для стеклотекстолита,
с рабочей длиной >2,2 мм и подходящей цангой. Проверить реальный диаметр/биение.
Большие отверстия фрезеруются по рассчитанному радиусу (Dотв−Dфрезы)/2,
из уже готового пилота Ø2 мм. Ø3,2 и Ø3,25 сохранены различными.
В контуре компенсация выполнена геометрией; G41/G42 не используются.
Четыре перемычки: примерно 1,5 мм ширина остатка после учёта фрезы и не менее
0,5 мм толщины при nominal t=2 мм. Высота прохода по tabs Z=−1,5 мм, полный рез −2,2.
Контур вырезать последним, перемычки удалить вручную после остановки и снятия платы.

## Заголовок, окончание, проверка

```gcode
(VERIFY G54, TOOL, RPM AND CLEARANCE)
G17 G21 G40 G49 G54 G80 G90 G94
M5
T1
M0
G0 Z5.000
M3 S10000
G4 P2
(BODY)
G0 Z5.000
M5
M9
M30
```

S10000 и +5 здесь пробные, подставить проверенные. Начальное положение по Z,
рабочий ноль и запас хода должны быть известны до запуска. При ручной смене
инструмента выполнять повторное измерение Z отдельной операцией.

`check_gcode.py` работает на стандартном Python без KiCad. Проверяет модальные
мм/абсолют/G54/G94, рабочие границы с радиусом инструмента, минимальный Z,
I/J-дуги с их экстремумами, подачи, S, T, M5 перед паузой, быстрый XY ниже
безопасного уровня, запрет циклов/макросов/смены систем координат. R-дуги,
G91, G53, G92, probing и смена TLO внутри файла отвергаются: преобразовать в
поддерживаемые команды или отдельно проверить другим симулятором.

```powershell
python check_gcode.py jobs/01_contacts_D1mm_SETUP_REQUIRED.ngc --x -2 38 --y -2 62 --z -2.6 8 --start 0 0 5 --tool-radius 0.5 --smax 10000
python check_gcode.py jobs/02_PILOTS_ONLY_D2mm_SETUP_REQUIRED.ngc --x -2 38 --y -2 62 --z -2.9 8 --start 0 0 5 --tool-radius 1
python test_check_gcode.py
```

`--start` — фактическая позиция в G54 после отмены TLO, а не универсальное допущение.
Границы примера — рабочая область около платы, не машинные 300×180×45 мм.
Не включают модели прижимов/шпинделя; не доказывают отсутствие столкновений,
правильный ноль, режимы резания или правильность зеркала. Реальный `$$` и homing
нужны для проверки машинных пределов. Передача файла в GRBL `$C` проверяет парсер
без движения; это не пробный рез и не проверка закрепления.

## Перед запуском

- Проверить актуальность файла, бумажный шаблон 1:1, вывод 1 RJ-10 и порядок OLED.
- Понять статус каждого файла: пилот не окончательный размер; 03 эксперимент;
  04/05 требуют другого инструмента. Не зеркалировать готовые jobs повторно.
- Измерить толщину, диаметр/угол сверла, вылет, биение, проверить цангу и крепление.
- Ровный жертвенный стол, сплошная приклейка, сухая плата; никаких прижимов на пути.
- Проверить G54, Z0, карту/сторону, $30/$31/$32, направление шпинделя, аварийную остановку.
- Удалить щуп/провод перед вращением; обеспечить вытяжку стеклотекстолитовой пыли,
  защитные очки и подходящую защиту дыхания. Перчатки не носить у вращающегося шпинделя.
- Прогнать статический проверяющий скрипт, посмотреть траекторию в bCNC, проверить
  GRBL в `$C`, затем соответствующий AIR5 с M5, height map выключена и весь Z=+5.
- Сделать пробу на таком же материале и плёнке: отверстия, ширина реза, экспозиция,
  проявление, устойчивость к FeCl3, итоговая ширина дорожки и зазоры при меди 70 мкм.
- На химическом столе — очки, совместимые перчатки и пластик по SDS поставщика.
  Не хранить FeCl3 в металле; растворы с медью/промывные воды собирать отдельно,
  не сливать в канализацию, передавать на соответствующую утилизацию.
- Не оставлять обработку без наблюдения; при изменении звука, забивании или отслоении остановить.

## Типовые ошибки

| Симптом | Что проверить/исправить |
|---|---|
| Отверстия смещены относительно меди | Общий Drill/Place Origin, один масштаб, одинаковое зеркало; не zero-start отдельно для каждого файла. |
| Детали получились зеркально | Не путать готовый BOTTOM_VIEW, raw Gerber и INK_DOWN; проверить асимметричный J2 до травления. |
| GRBL error:20 | M6, G81/G83, G64 или макросы; нужный постпроцессор, развернуть циклы, не удалять команды вслепую. |
| Резист срывает/размазывает | Тип/отверждение, PET, адгезия, биение, глубина; купон, меньше нагрузка, выбрать оптический процесс. |
| Щуп не срабатывает на плёнке | Диэлектрик; не увеличивать ход вниз, сменить способ измерения. |
| Гравер съедает дорожки | Эффективная ширина V, глубина/карта, биение; кончик 0,2 для 70 мкм и зазора 0,25 слишком близок к пределу. |
| После травления медные острова | Была только isolation; нужен полный NCC/выборка маски либо нормальная проявка. |
| Медь не травится в пробелах | Остаточная вуаль резиста, неверная полярность, проявка, загрязнение, состояние раствора. |
| Дорожки тонкие/рваные | Подтравливание 70 мкм, передержка, дырки маски; уменьшить лишнее время, подобрать процесс на купоне. |
| Отверстие не выходит полным Ø | Не учтено острие сверла/толщина; пересчитать глубину и запас в жертвенный стол. |
| Плата ушла на последнем проходе | Контур слишком рано, слабая приклейка/tabs; удержание и контур последним. |
